# CL-3Y — Scientific readiness audit of the CL-3X H1 pilot

**Result: NO_GO — nine of nine scientific/authorization gates remain OPEN.** This is a read-only evidence audit, not a scientific approval, compute authorization or experimental result.

The audit reads the [CL-3X preregistration](cl3x_h1_preregistration.json), validates it against the frozen CL-2 candidate and CL-3A NO_GO readiness state, and maps each open gate to existing source/protocol evidence and missing independent review. The machine-readable audit is generated by [`cl3y_readiness_audit.py`](cl3y_readiness_audit.py). It does not run a model, produce data, contact APIs or mutate the approval state.

## Suggested sequence, without training

1. Complete source/data provenance and causal-equivalence review first: they govern whether results can answer H1 at all.
2. Finalize observational scope and interpretability: match model quality, record activity strata, account for observer overhead, and distinguish training from inference.
3. Freeze uncertainty, acceptance/failure thresholds and source-pinned result artifacts; document energy explicitly as NOT_MEASURED unless hardware instrumentation is separately reviewed.
4. Have an independent scientific reviewer examine the exact protocol and future runner.
5. Only then consider asking Marcus for a **separate, explicit compute-training authorization** at an exact source/protocol commit.

**No claim of decreased physical energy, improved catastrophic forgetting, Loihi or photonic advantage is supported by this audit.** The old CL-3A NO_GO gate and CL-3X NO_GO are unchanged. A passing GitHub Actions run, a Codex approval or a merged PR is not permission to run experiments.
