# ECG200 benchmark protocol — PNN-v1 Exp001

## Purpose

Establish the first practical benchmark for Debatt-AI Photonic Neural Network v1.

Both models must use the canonical ECG200 TRAIN split for training and TEST split for final evaluation. No model may receive a more favorable split.

## Conventional baseline

**MLP-ReLU:** 96 → 64 → 32 → 2.

This is intentionally simple. Its role is to provide a conventional neural reference under the same data conditions, not to represent the strongest possible ECG classifier.

## PNN-v1 candidate

**PNN-v1-alpha1** will be the first Q.ANT-native candidate. Its design must use the architecture lessons from the Toolkit discovery phase, especially hierarchical/low-fan-in computation, and Q.ANT KAN/Fourier-style nonlinear operations.

The implementation must freeze exact preprocessing, layer widths, initialization/training settings and evaluation procedure before final test evaluation.

## Evaluation

Primary metric: test accuracy.

Also record parameter count and Q.ANT/reference numerical compatibility metrics where applicable. The result must clearly distinguish ordinary reference computation from Q.ANT software/simulation-backend execution.

No latency, throughput, energy-efficiency or other real photonic hardware claims may be inferred from this experiment.
